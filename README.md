# 基于 STM32 与 LVGL 的智能 GPS 码表/自行车仪表盘系统

本项目是一款基于 STM32 微控制器和 **LVGL (Light and Versatile Graphics Library) v9** 图形框架开发的智能自行车码表系统。项目集成了 GPS 经纬度数据解析、实时速度/距离计算，以及高级地图瓦片（Map Tiles）的像素坐标转换与动态渲染。

| Supported Targets | STM32F405RGTx (高性能版) | ARM Cortex-M4 | 
| ----------------- | ----------------------- | ------------- |

---

## 🚀 核心功能特性

* **高级 GUI 渲染（LVGL v9）**：利用 LVGL 的 Subjects 机制、Grid 布局和对象事件回调，构建高刷新率、低内存占用的动态仪表盘界面。
* **GPS 轨迹与数据可视化**：实时解析标准 NMEA 协议，提取经纬度、航向和卫星时间，动态计算当前车速与累计里程。
* **地图瓦片渲染算法**：实现高效的**墨卡托投影算法**，将全球 GPS 物理坐标实时转换为本地液晶屏的像素坐标，支持动态更新和局部刷新地图瓦片。
